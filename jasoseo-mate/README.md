# 자소서 메이트 UI 목업

이 프로젝트는 자기소개서 관리·경험 관리·AI 첨삭·공고 추천·학습 로드맵·면접 연습 화면을 확인하기 위한 독립 실행형 프론트엔드 목업입니다. API와 DB는 연결하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 디자인 토큰

`src/index.css`의 `:root`에 공통 색상·간격·모서리·타이포그래피 변수를 정의했습니다. 네이비 `#30364F`, 회백색 `#F5F8F9`, 쿨 그레이 `#EAF0F2`, 블루 `#1684B5`를 기준으로 합니다.

## 팀 프로젝트에 합칠 때

이 ZIP은 독립 목업이며, 팀 저장소의 `web/src/app/` 및 `web/src/features/` 전체를 포함하지 않습니다. 따라서 팀 프로젝트의 공통 라우터·레이아웃을 덮어쓰지 마세요. 실제 통합 시에는 기존 `web/src/features/learning/`에 학습 로드맵 화면을 분리하고, 팀의 `theme.css` 변수 및 `routes.jsx` 등록 규칙에 맞춰 이식해야 합니다.

현재는 시연용 데이터와 브라우저 로컬 상태를 사용합니다. 인증 토큰이나 실제 개인정보를 넣지 마세요.
