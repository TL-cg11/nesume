## 2. 정의 (사용자 결정 10/27)

- **자소서 상태**: `작성 중` · `검토 중` · `완료` 3가지(발표 시안). 비우면 "상태 없음"이고 대시보드에서는 작성 중으로 셉니다
  - 자소서 상세의 상태 입력은 선택 목록으로 바뀌었습니다. API도 이 값만 받습니다(그 외 422). DB 제약은 추가하지 않아 기존 값은 그대로 남습니다
- **작성 중인 자기소개서** = `완료`가 아닌 자소서(상태 없음 포함)
- **전체 작성 진행률** = 저장된 본문(버전)이 있는 문항 수 / 전체 문항 수(삭제된 자소서·문항 제외)
- **최근 수정** = 자소서 정보 수정과 버전 저장 중 늦은 시각
