## 1. 결과 요약

- 경험 데이터 등록·조회·수정·삭제 API와 화면 (spec 3.5 필드: 제목, 기간, 유형, 역할, 사용 기술, 성과, 상세 서술, 태그)
- 태그 필터 (여러 개 선택 시 **하나라도 포함**, 입력값 그대로 비교 — 개인정보가 든 태그는 검색되지 않음)
- 자소서 문항에 경험 끌어오기: 편집기 본문 끝에 요약 한 문단 추가 + 어떤 문항이 어떤 경험을 썼는지 기록
- 본인 경험만 접근 가능, 다른 사용자 것은 "없음(404)"

## 2. 저장·조회 흐름

```
등록·수정: 민감정보 차단(A1) → 문자열 필드 토큰화(A1, 매핑은 B7) → DB 저장 → 개인 인덱스 반영(C3)
조회:      소유자 본인에게만 토큰을 원문으로 복원
```

- 토큰화 대상: PII가 들어갈 수 있는 **문자열 필드 전부** (제목, 유형, 역할, 성과, 상세, 사용 기술, 태그)
- 주민번호·계좌번호 등이 들어오면 저장 거부(422). 안내 문구는 spec 9.1 그대로
- 현재 A1·C3가 없어 각 지점은 입력을 그대로 통과시킴. 추합 시 지점 파일만 교체

## 3. 삭제

- 자소서와 같은 규칙: 소프트 삭제(목록에서 사라짐) → 30일 후 완전 삭제(B20)
- 임베딩은 30일 후 완전 삭제 때 지움

## 4. API

| 동작 | 경로 |
|---|---|
| 경험 목록(태그 필터)·등록 | `GET /experiences?tags=a&tags=b`, `POST /experiences` |
| 경험 단건·수정·삭제 | `GET/PATCH/DELETE /experiences/{id}` |
| 문항에 연결된 경험 목록·연결 | `GET/POST /resumes/{rid}/questions/{qid}/experiences` |
| 연결 해제 | `DELETE /resumes/{rid}/questions/{qid}/experiences/{eid}` |

## 10/28 화면 개편(멘토링 전 프론트 수정)

- **유형 드롭다운**: 프로젝트 / 활동 / 수상 / GitHub / 기타. 유형별로 칸 이름·예시 문구·표시 여부가 바뀐다(`templates.js`). 저장 칸은 그대로(spec 3.5)
  - 활동·수상은 사용 기술 칸 숨김(숨긴 칸 값은 저장 안 함), 수상은 수상일(월 하나, 시작·종료에 같은 값), 수여 기관은 역할 칸에 저장
  - GitHub는 B14 초안 생성이 폼 안에 들어옴
  - 목록에 없는 예전 자유 입력 유형은 '기타'로 표시·저장
- **기간**: 날짜 칸(연도 6자리까지 입력돼 월이 연도로 넘어가던 문제) → **월 선택칸**(YYYY-MM, 저장은 그 달 1일). 종료가 시작보다 앞서면 저장 불가
- **작성·수정을 별도 주소로**: `/experiences/new`, `/experiences/:id/edit`. 작성 화면에 목록을 보이지 않고, 메뉴 '경험'을 누르면 목록(초기 화면)으로 돌아간다
- 기간 표시는 월 단위, 월 하나면 한 번만(`summary.period`)
- **열람 화면** `/experiences/:id`: 목록 행(빈 곳 포함)을 누르면 열림. 저장한 항목을 유형별 칸 이름으로 표시(비어 있는 항목은 생략), 목록·수정·삭제 버튼. 목록의 수정·삭제 버튼은 그대로 동작
- **목록 양식**(자소서 목록과 같음): 카드 안 행마다 경험 이름·기간만. 수정·삭제·상세는 열람 화면에서만. 빈 목록·태그 필터 결과 없음 안내 카드. 태그 필터는 그대로
- **경험 끌어오기 → 연결만**(part2_guide 4.65, 4.22 대체): 문항↔경험 연결만 기록하고 본문에는 넣지 않는다(연결한 경험은 AI 참고 자료). 연결 목록은 카드 양식(이름·기간·연결 해제, 행 클릭 시 경험 열람), 이미 연결한 경험은 선택 목록에서 제외. 본문용 요약 함수 `experienceSummary` 삭제
- 남은 것: A 기능(A6·A7 등)이 문항에 연결된 경험을 아직 읽지 않음 → A에 연결 요청 필요(`GET /resumes/{rid}/questions/{qid}/experiences`, 서버 함수는 experiences 저장소)
- **유형 필터**: 목록 위 칩(전체·프로젝트·활동·수상·GitHub·기타, 개수 표시). 태그 필터와 함께 적용(둘 다 만족). 예전 자유 입력 유형은 기타
