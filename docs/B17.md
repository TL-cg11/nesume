## 1. 결과 요약

멘토가 공유받은 자소서를 **읽기 전용으로 보고 문단마다 코멘트**를 남깁니다(spec 3.7). 작성자는 공유 패널에서 코멘트를 원문으로 보고 확인 표시를 합니다.

| 결정(사용자, 10/26) | 내용 |
|---|---|
| 문단 기준 | 빈 줄. 빈 줄이 없으면 문항 전체가 한 문단 |
| 코멘트 위치 | 공유 시점에 고정된 버전의 문단. 버전이 고정이라 위치가 어긋나지 않음 |
| 답글 | 없음. 멘토 → 작성자 단방향, 작성자는 "확인"만 |
| 공유 종료 후 | 작성자는 계속 보관·열람, 멘토는 접근 불가(쓰기·수정·삭제 모두 404) |
| 개인정보 | 민감정보 거부 + 토큰화 저장(B4·B7과 같음). 작성자에게는 원문, 멘토에게는 `(전화번호 비공개)` 형태 |

## 2. 화면

**멘토** (상단 메뉴 "받은 공유")
- 받은 공유 목록: 자소서 제목, 종료일
- 열람: 문항별로 문단을 나눠 보여주고, 문단마다 "코멘트 남기기". 내 코멘트는 수정·삭제 가능
- 편집·다운로드 기능 없음. 멘토가 아닌 계정은 "멘토 계정에서만 볼 수 있습니다"

**작성자** (자소서 상세 → 멘토 공유 패널)
- 공유마다 "코멘트 N · 새 M" → 펼치면 문항·문단 인용·코멘트 원문, "확인" 버튼

## 3. API

| 대상 | 기능 | 주소 |
|---|---|---|
| 멘토 | 열람(문단·내 코멘트 포함) | `GET /mentor/shares/{id}` — `questions[].paragraphs`, `questions[].comments` 추가 |
| 멘토 | 코멘트 작성 | `POST /mentor/shares/{id}/comments` `{version_id, paragraph_index, body}` |
| 멘토 | 수정·삭제 | `PATCH`·`DELETE /mentor/shares/{id}/comments/{comment_id}` |
| 작성자 | 코멘트 보기(원문) | `GET /shares/{id}/comments` |
| 작성자 | 확인 표시 | `POST /shares/{id}/comments/{comment_id}/read` |
| 작성자 | 공유 목록 | `comment_count`, `unread_count` 추가 |

- 코멘트 1~1000자. 공유에 고정되지 않은 버전이나 없는 문단 → 422
- 저장: `share_comments`(작성자 소유, 개인 등급, B8 등급표 추가). 공유·작성자 계정 삭제 시 함께 삭제
