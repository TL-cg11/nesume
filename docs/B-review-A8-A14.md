## A1 버그 수정 (11/3)

- **붙여 쓴 계좌·카드번호 미탐**: `ACCOUNT` 규칙은 구분자(`-`·공백)가 있어야 잡아서 "계좌번호 1234567890123"이 그대로 모델에 갔다. `ACCOUNT_LABELED` 추가 — 앞에 라벨(계좌·통장·입금·송금·은행·뱅크·카드)이 있고 숫자 10~16자리일 때만 잡는다. 라벨 없는 긴 숫자(학번·주문번호·타임스탬프)는 잡지 않는다(계좌는 거절 대상이라 모두 잡으면 과차단). 평가 시나리오 기대값 영향 없음
- **조사 보정이 일반 낱말을 바꿈**: 복원 시 글 전체에 조사 보정을 돌려 "있는"→"있은", "먹는"→"먹은"이 됐다. 복원한 값 **바로 뒤에 붙은 조사만** 고치도록 변경. 숫자·영문으로 끝나는 값(전화번호·이메일) 뒤 조사는 그대로 둔다
- 테스트: 탐지 3건·오탐 방지 3건, 복원 조사 보정 2건 추가. 전체 통과
