## 1. 결과 요약

- 자소서·문항 생성/조회/수정/삭제, 문항별 버전 저장·타임라인·비교·복원 API
- 자소서 목록, 문항 편집기, 버전 기록, 버전 비교 화면
- 본인 자소서만 접근 가능, 다른 사용자의 자소서는 "없음(404)"으로 응답

## 2. 주요 규칙 (spec 3.1)

- 저장할 때마다 새 버전 생성, 덮어쓰기 없음
- 이전 버전 복원 = 그 내용으로 새 버전 생성 (기록에 "vN에서 복원" 표시)
- 문항당 버전 50개 초과 시: 저장은 되고 "50개 초과" 안내만 표시. 압축 방식은 팀 확인 후 구현
- 자소서·문항 삭제는 소프트 삭제(목록에서 사라짐), 30일 후 완전 삭제(B20)
- 등급·소유자·생성 방식(source)은 요청으로 지정할 수 없음. 서버가 부여

## 3. API

| 동작 | 경로 |
|---|---|
| 자소서 목록·생성 | `GET/POST /resumes` |
| 자소서 상세(문항 + 최신 버전)·수정·삭제 | `GET/PATCH/DELETE /resumes/{id}` |
| 문항 추가 | `POST /resumes/{id}/questions` |
| 문항 수정·삭제 | `PATCH/DELETE /resumes/{id}/questions/{qid}` |
| 버전 저장(수동)·타임라인 | `POST/GET .../questions/{qid}/versions` |
| 버전 단건 | `GET .../versions/{vid}` |
| 두 버전 비교 | `GET .../versions/diff?from=1&to=2` |
| 복원 | `POST .../versions/{vid}/restore` |

## 추가 (2026-10-27): 자소서·버전 상한 (10/26 회의 결정)

spec 3.1의 "문항당 50개 초과 시 보관 요약으로 압축" 대신 **상한**을 둡니다.

| 대상 | 상한 | 넘으면 | 해결 |
|---|---|---|---|
| 문항당 버전 | 50개 | 저장·복원 거부(409 `version_limit_reached`) | 버전 기록에서 지울 버전을 골라 **삭제** 후 저장 |
| 사용자당 자소서 | 50개(삭제되지 않은 것) | 생성 거부(409 `resume_limit_reached`) | 기존 자소서를 삭제하면 바로 생성 가능 |

- 버전 삭제 `DELETE /resumes/{id}/questions/{qid}/versions/{vid}`(새 기능). 버전 **수정 금지는 그대로**이고 삭제만 허용
- 지울 수 없는 버전(409 `version_in_use`): 지원 기록이 고정 참조하는 버전, 유효한 멘토 공유가 고정한 버전
- 버전 번호는 재사용하지 않습니다(51, 52 … 계속)
- 화면: 버전 기록에 `N/50`과 버전별 "삭제", 자소서 목록 제목에 `N/50`
- 응답의 `over_limit`는 이제 항상 false(다른 코드 호환용으로 남김)

## 10/28 후속: 문항 → 글 다듬기(A6) 링크

- 문항 편집 화면 제목 옆 "글 다듬기" → `/writing?resume=<자소서ID>&question=<문항ID>`(A 요청)
- A6 리라이팅에서 고른 후보를 `/writing/rewrite/apply`로 이 문항의 **새 버전**(source=ai)으로 저장할 수 있게 된다. 링크가 없으면 본문 치환만 됨
- 저장하지 않은 수정이 있으면 "글 다듬기로 가기 전에 저장" 안내(리라이팅 결과는 서버에 저장된 버전 위에 새 버전으로 쌓임)
- A6 화면은 문항 본문을 미리 채우지 않음(사용자가 붙여 넣음) — A 쪽 결정 사항

## 10/28 글자 수 규칙

- 문항 제목 **300자**, 본문·글자수 설정 **10,000자**까지(서버 422, 화면 입력 제한). `schemas.QUESTION_TITLE_MAX·BODY_MAX` = 화면 `limits.js`
- 새 문항 글자수 기본 **1,000자**. 문항 추가 때와 작성 중(본문 아래 "글자 수 제한" 칸, 칸을 벗어나거나 Enter면 저장) 모두 바꿀 수 있음. 1~10,000 밖·빈 값은 보정
- 화살표 한 번에 **100자**
- 본문은 설정 글자수에서 더 입력되지 않음(붙여넣기도 잘림). 도달하면 빨간 안내. 글자수를 줄여 기존 본문이 넘치면 지우지 않고 빨간 경고 + 저장 비활성
- 예전 문항(글자수 미설정)은 10,000자로 봄

## 10/28 버전 기록 화면

- '이 버전으로 복원'·'삭제' 버튼 없앰
- 버전명·행 빈 곳 클릭 → 그 버전 본문을 편집칸에 불러옴(보는 버전 강조). 저장 전 수정이 있으면 확인
- 불러온 예전 버전을 고치지 않고 저장 → 복원 API(restored_from 기록, 'vN에서 복원' 표시). 고쳐서 저장 → 일반 새 버전
- 삭제: 행에 마우스를 올리면(또는 키보드 포커스) 오른쪽 끝 작은 빨간 × → 확인 후 삭제(지원 기록·공유 중이면 서버 409 안내)
