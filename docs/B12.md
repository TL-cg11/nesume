## 1. 결과 요약

| 항목 | 내용 |
|---|---|
| API | `POST /resumes/{id}/pdf {version_ids?, contact?{name,phone,email}}` → `{download_path, expires_at, filename}` (자소서 라우터에 포함, main.py 수정 불필요) |
| 템플릿 | **기본 하나**(10/30 사용자 결정 — tasks의 기본·간결·표 중 기본만, part2_guide 4.69). A4, 나눔고딕, 문항 제목 옆 글자 수, 문항 사이 구분선, 하단 쪽 번호 |
| 변환 | HTML → PDF(WeasyPrint 70.0) |
| 저장 | S3 비공개 `users/{id}/resumes/{resume_id}/{문서ID}.pdf`(B6, KMS) |
| 다운로드 | B6 1회용 토큰(10분, 사용 기록) → 화면이 로그인 상태로 받아 파일 저장 |
| 개인정보 | 본문 토큰은 **복원하지 않고** '(전화번호 비공개)'처럼 가림(spec 3.2). 제출용 연락처는 생성 시 입력한 값만 상단에(저장 안 함), 주민번호 등 민감정보는 거부 |
| 버전 | 기본은 문항별 최신. `version_ids`로 문항당 하나 고르기(이 자소서 본인 버전만, 아니면 422) |
| 권한 | 본인 자소서만(남의 것 404) → 멘토는 작성자 자소서 PDF를 만들 수 없음(spec 3.7) |

- 한글 줄바꿈: WeasyPrint가 `word-break: keep-all`을 지원하지 않아 낱말마다 줄바꿈 금지 상자(`white-space: nowrap`)로 감쌈. 보이지 않는 문자(U+2060)는 PDF에서 복사할 때 딸려 가 지원서 글자 수가 달라져 쓰지 않음(복사 텍스트 숨은 문자 0 확인). 띄어쓰기 없이 30자 넘는 낱말은 넘치지 않게 그대로

## 2. D에 요청할 것(앱 이미지)

`app/Dockerfile` base 단계에 추가:
```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends \
      libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz-subset0 fonts-nanum \
    && rm -rf /var/lib/apt/lists/*
```
`app/requirements.txt`에 `weasyprint==70.0` 추가. 그 뒤 화면에서 바로 동작(코드 변경 없음).
