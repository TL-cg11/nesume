## 2. 형식

| 파일 | 용도 |
|---|---|
| `scenarios_sheet.yaml` | 평가 러너(B16)·테스트가 읽는 원본 형식 |
| `scenarios_sheet.csv` | 사람이 보는 생성본(엑셀·노션·회의·B22 리포트). UTF-8 BOM이라 엑셀에서 한글 정상 |

**CSV 열(spec 11.1 기준)**: id, source(태스크), category, channel(api/llm), role, feature(기능), query(질의, 여러 턴은 `1) … 2) …`), request(api 요청), preconditions(사전 조건), expect_decision(기대 판정), expect_message(기대 안내 문구), expect_checks(추가 확인 항목), known_miss(알려진 한계), note(근거)

- **CSV·YAML은 손으로 고치지 않습니다.** 원본을 고친 뒤 다시 생성합니다. 테스트가 생성본과 원본이 다르면 실패합니다
- 생성 명령: `eval/build_sheet.py` 맨 위 주석 참고(테스트 컨테이너에서 실행)

**검사 규칙**: ID 형식(`<태스크>-<유형>-<번호>`, 태스크 일치), 전체 ID 중복 없음, 기대 판정 3값, 역할·근거 필수, api는 request만·llm은 질의만, 태스크별 건수(tasks.md)
